# Чек-лист данных для интеграции платежей (Robokassa)

> Что нужно собрать, чтобы платёжный модуль заработал вживую. Отмечай по мере получения.
> Контекст — [payments-setup.md](payments-setup.md). Составлено 20.09.2026.

**Минимум, чтобы начать и тестировать:** блок 1 (хватит тестовых паролей). Фискализация не
нужна (блок 2 закрыт). Блоки 3–4 нужны ближе к боевому запуску, блок 5 — своя задача.

---

## 1. Доступы Robokassa → в `.env`

- [ ] `MerchantLogin` (идентификатор магазина)
- [ ] Пароль #1 — **боевой**
- [ ] Пароль #2 — **боевой**
- [ ] Пароль #1 — **тестовый**
- [ ] Пароль #2 — **тестовый**
- [ ] Алгоритм подписи, выбранный в кабинете (MD5 / SHA-256)

## 2. Фискализация — НЕ требуется

Решение заказчика (20.09.2026): чек ККТ не формируем, принимаем добровольные пожертвования.
`Receipt` и СНО в интеграции не используются, фискализацию в Robokassa не подключаем.
Блок закрыт — сбор данных по чеку не нужен.

## 3. Решения по продукту (от заказчика)

- [ ] Набор способов оплаты и порядок (по умолчанию: СБП → SberPay → T-Pay → карта)
- [ ] Пресеты сумм (по умолчанию 100 / 500 / 1000 ₽; минимум 100 ₽ — согласован)
- [ ] Текст назначения платежа (Description)

## 4. Реквизиты запасного пути (ручной перевод, ManualProvider)

- [ ] Наименование организации, ИНН / ОГРН
- [ ] Расчётный счёт
- [ ] БИК
- [ ] Корр. счёт
- [ ] Банк
- [ ] QR СБП (если будет)

## 5. Инфраструктура (на нашей стороне)

- [ ] Публичный HTTPS-URL под колбэк (локально — туннель cloudflared/ngrok на :3001; прод — домен + Nginx/TLS)
- [ ] В кабинете Robokassa: Result URL (метод **POST**)
- [ ] В кабинете Robokassa: Success URL
- [ ] В кабинете Robokassa: Fail URL

---

## Итоговый `.env` (после сбора всего)

```
PAYMENT_PROVIDER=robokassa
PAYMENT_MERCHANT_ID=      # MerchantLogin
PAYMENT_SECRET_KEY=       # Пароль #1 (боевой)
PAYMENT_WEBHOOK_SECRET=   # Пароль #2 (боевой)
PAYMENT_TEST_SECRET_KEY=      # Пароль #1 (тестовый)
PAYMENT_TEST_WEBHOOK_SECRET=  # Пароль #2 (тестовый)
PAYMENT_IS_TEST=1         # 1 — тестовый режим, 0 — боевой
PAYMENT_PUBLIC_URL=       # публичный base-URL для Result/Success/Fail
# Receipt/СНО не нужны — чек не формируем
```
