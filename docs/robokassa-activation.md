# Robokassa: активация приёма реальных платежей

> Что проделать **на стороне Robokassa**, чтобы принять первый реальный (не тестовый)
> платёж. Организационная часть — на заказчике/НКО, техническая — на нас.
> Связанные документы: [payments-setup.md](payments-setup.md) (полный контекст),
> [payments-robokassa-cabinet.md](payments-robokassa-cabinet.md) (маппинг кабинет ↔ `.env`).
> Сверено с процессом Robokassa на 22.09.2026.

---

## Главное

Реальные деньги пойдут только после **двух** событий:
1. магазин **прошёл модерацию**, и
2. **активирован вывод средств** (подтверждён договор с ООО «Робокасса»).

До этого доступен только **тестовый режим** — ненастоящие деньги. Модерация занимает
**недели**, поэтому организационную часть (блок 1) запускаем немедленно и параллельно
с разработкой.

Держатель договора — **организация-получатель пожертвований** (НКО / мечеть), не
частное лицо. Нужен доступ к её ИНН, учредительным документам и расчётному счёту.

---

## Блок 1 — запустить сразу (самое долгое, недели)

- [ ] Зарегистрироваться на robokassa.com **на организацию-получатель**, указать её ИНН.
- [ ] Заполнить анкету (деятельность, руководитель, бенефициары), загрузить сканы
      документов. Типовой пакет для юрлица/НКО (точный список подтвердит Robokassa):
      устав, лист записи ЕГРЮЛ/ОГРН, свидетельство ИНН, документ о назначении
      руководителя, карточка с реквизитами расчётного счёта, паспорт руководителя.
- [ ] Создать магазин: **Идентификатор** (= `MerchantLogin`), **URL** = `https://mechetshamil.ru`,
      расчётный счёт организации, ответственное лицо, email поддержки.
- [ ] Запросить **спецтариф для НКО/фондов** (без абонплаты) и письменно зафиксировать
      комиссии по способам оплаты (нужны для формулировки «комиссия включена в сумму»).
- [ ] Подать магазин **на модерацию**.

## Блок 2 — условие прохождения модерации (сайт)

Robokassa при проверке смотрит содержимое сайта, поэтому он должен быть **развёрнут на
боевом домене с HTTPS до подачи на модерацию**. На сайте обязаны быть:

- [ ] реквизиты организации: наименование, ИНН/ОГРН, адрес;
- [ ] оферта / условия оплаты и описание, на что сбор;
- [ ] политика конфиденциальности (152-ФЗ) и согласие на обработку ПДн в форме;
- [ ] контакты.

Данные на сайте должны совпадать с анкетой — расхождения затягивают модерацию.

## Блок 3 — забрать из кабинета → отдать разработчику (в `.env`)

Из **Технических настроек** магазина:

- [ ] `MerchantLogin` → `PAYMENT_MERCHANT_ID`
- [ ] Пароль #1 (боевой) → `PAYMENT_SECRET_KEY`
- [ ] Пароль #2 (боевой) → `PAYMENT_WEBHOOK_SECRET`
- [ ] Тестовая пара паролей → `PAYMENT_TEST_SECRET_KEY` / `PAYMENT_TEST_WEBHOOK_SECRET`
- [ ] Алгоритм подписи (MD5 / SHA-256) → `PAYMENT_HASH_ALGORITHM` (должен совпадать с кабинетом)

Подробный маппинг и подводные камни — [payments-robokassa-cabinet.md](payments-robokassa-cabinet.md).

## Блок 4 — вписать в кабинет (Технические настройки)

- [ ] **Result URL** = `https://mechetshamil.ru/api/payments/robokassa/result`, метод **POST**
- [ ] **Success URL** = `https://mechetshamil.ru/spasibo`
- [ ] **Fail URL** = `https://mechetshamil.ru/`
- [ ] Алгоритм подписи в кабинете = `PAYMENT_HASH_ALGORITHM` в `.env`

## Блок 5 — фискализация НЕ подключается

Чек ККТ не формируем — принимаем добровольные пожертвования (решение заказчика 20.09.2026).
`Receipt` и СНО в интеграции не участвуют, Робочеки в кабинете не подключаем. В коде уже учтено.

## Блок 6 — после одобрения модерации

- [ ] **Активировать вывод средств**: перевести 1 ₽ с расчётного счёта организации на счёт
      ООО «Робокасса» (реквизиты в кабинете, назначение — «Подтверждение о заключении
      Договора об оказании услуг с ООО Робокасса»); либо подписать бумажное подтверждение
      о присоединении и отправить почтой. Активация — до 3 рабочих дней.
- [ ] Включить **боевой режим** магазина в кабинете.
- [ ] Разработчик ставит боевые ключи и `PAYMENT_IS_TEST=false`.

## Блок 7 — первый реальный платёж

- [ ] Сделать контрольный платёж настоящей картой (например 100 ₽).
- [ ] Проверить: деньги дошли, вебхук отработал, страница `/spasibo` показала успех,
      донат в БД в статусе `paid`.
