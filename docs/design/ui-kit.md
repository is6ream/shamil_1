# UI-кит

День 3 роудмапа · 2026-09-21

Живой каталог: [ui-kit.html](ui-kit.html) — открыть в браузере. Здесь — решения и то,
что из них следует для вёрстки.

## Что изменилось по сути

До дня 3 UI-кит существовал как инлайновый `<style>` внутри
[prototype.html](prototype.html), и он же был скопирован в [thanks.html](thanks.html).
Две копии кнопок, заглушки и всей сцены анимации. Правка тайминга на главной не доезжала
до экрана оплаты, и наоборот.

Теперь это три файла, подключённые всеми страницами одинаково:

| Файл | Что внутри | Строк |
| --- | --- | --- |
| [tokens.css](tokens.css) | Цвет, типографическая шкала, отступы, форма, тени, движение, фокус | ~150 |
| [kit.css](kit.css) | Компоненты поверх токенов: кнопки, карточки, панели, шкалы, поля, рейтинги | ~400 |
| [scene.css](scene.css) | Сцена первого экрана: ладони → монета → мечеть → полумесяц | ~110 |

**Ни одного «сырого» цвета в компонентах** — только токены. То, что видно в каталоге,
и есть то, что на странице: отдельной «дизайнерской» копии стилей больше не существует,
и расходиться нечему.

## Четыре решения, которые стоит знать до вёрстки

### 1. Компоненты не знают собственного цвета

Между палитрой и компонентами стоит слой ролей: `--surface`, `--text-strong`, `--text-soft`,
`--border`, `--accent`, `--on-accent`, `--focus`. Роли переопределяются один раз — на
`.panel`, `footer` и вспомогательном `.on-dark`, — и любой блок, положенный внутрь,
инвертируется сам.

В прототипе дня 2 на это уходило семь ручных правил вида `.panel .btn-primary`,
`.panel .sub`, `.panel .stub`. Каждый новый компонент требовал восьмого, и про какой-нибудь
обязательно забывали. Теперь кнопка на градиентной панели белая с тёмно-синим текстом
без единой строки, написанной специально для неё.

Тёмная тема при этом **не появилась и не планируется**: `.on-dark` — это инверсия панели,
а не тема. Тема удвоила бы проверку контраста, которой в бюджете 32 часов нет.

### 2. Прогресс-бар заполняется трансформацией, а не шириной

`width` каждый кадр гоняет layout; `transform` уезжает на композитор. Но наивный
`scaleX()` сплющил бы круглый торец заливки в вертикальную грань — на шкале 5,3% это
особенно заметно.

Приём: заливка во всю ширину дорожки, сдвинутая влево на `100% − p`.

```css
.track > .fill { transform: translateX(calc(-100% + var(--p, 0%))); }
.track.in > .fill { animation: fill-in var(--dur-bar) var(--ease-bar) both; }
@keyframes fill-in { from { transform: translateX(-100%); } }
```

Правый торец остаётся круглым, левый обрезается скруглением дорожки. Значение приходит
из `--p` — посчитанного и **обрезанного по 100% на сервере**.

Побочный эффект важнее самой оптимизации: **без JavaScript шкала статична и показывает
верное значение**. Класс `.in`, который вешает `IntersectionObserver`, добавляет только
прокрутку от нуля. Раньше значение проставлял скрипт из `data-w`, то есть без JS обе
шкалы сбора стояли на нуле.

Разметка:

```html
<div class="track" role="progressbar" aria-valuenow="72" aria-valuemin="0" aria-valuemax="100"
     aria-label="Собрано за месяц" style="--p:72%"><i class="fill"></i></div>
```

### 3. Пресеты, способы оплаты и чекбоксы — настоящие поля

`.chip`, `.pay`, `.check` в прототипе дня 2 были `<span>` и `<div>` с классом `.on`.
Мышью выглядело правильно. С клавиатуры форма была непроходима, а скринридер не объявлял
ни выбранную сумму, ни способ оплаты.

Теперь это `<label>` с настоящим `input[type=radio]` / `input[type=checkbox]` внутри
`.sr-only`, а состояние берётся из `:has(:checked)`. Группы обёрнуты в `<fieldset>`
с `<legend>` — иначе радиогруппа не объявляется как группа.

```html
<label class="chip"><input class="sr-only" type="radio" name="amount" checked> 100 ₽</label>
```

На форме, через которую идут деньги, это не косметика: часть жертвователей — пожилые люди,
многие из них ходят по странице с клавиатуры или с экранным диктором.

### 4. Фокус задан один раз на весь сайт

`outline: 3px solid var(--focus)`, отступ 2 px. Цвет — токен, поэтому на градиентной панели
кольцо автоматически белое. Контраст синего кольца на кремовом — 5.36 при требуемых для
нетекстовых элементов 3:1.

В прототипе дня 2 `:focus-visible` не был задан нигде: человек с клавиатуры не видел,
где находится, в том числе внутри платёжной формы.

Проверка — клавишей `Tab` по [ui-kit.html](ui-kit.html#forms): форма проходится целиком,
ни разу не тронув мышь.

## Hero

Первый экран — слоган и CTA, а не информация: прямое требование ТЗ и главное отличие
от референса, у которого H1 — подпись к фотографии.

| | |
| --- | --- |
| Высота | `88svh` — не 100: нижний край следующего блока должен выглядывать |
| Заголовок | Lora 600, `clamp(35 → 68px)`, «за 100 ₽» акцентным синим с подчёркиванием |
| Сцена | `scene.css`, ~5 с, один проход |
| На телефоне | Сцена **над** заголовком, уменьшена до 76 vw, подпись под ней скрыта |

### Состояния

**Первый день сбора.** Строка «уже собрано N ₽ от M человек» исчезает целиком,
надзаголовок меняется со «Сбор идёт · 1 204 человека» на «Сбор открыт». «Собрано 0 ₽»
убивает доверие сильнее, чем отсутствие строки, а выдумывать доноров мы не будем.

**`prefers-reduced-motion`.** Сцена показывает финальный кадр: мечеть, ладони, полумесяц
и подпись на месте. Исчезает только монета — её единственная роль в том, чтобы упасть.
Экран не пустой и не выглядит сломанным.

## Блок цели

Двойная шкала — главное заимствование у референса. Месячная сверху и крупнее общей:
при цели 240 млн общая на старте показывает доли процента и читается как провал.

**Остаток переведён в пожертвования по 100 ₽:** «17 000 человек по сотне» звучит достижимо,
«1 700 000 ₽» — нет. Та же цифра, другая единица измерения.

### Состояния

| Состояние | Что показываем |
| --- | --- |
| Обе цели заданы | Месячная 13 px + общая 7 px, под ними три счётчика |
| Месячная цель не задана | Блок схлопывается до одной шкалы, она становится крупной |
| Месяц перевыполнен | Шкала полная, процент настоящий (118%), подпись «Цель месяца достигнута — собираем сверх» |
| Первый день | Ноль **показываем**: рядом есть шкала и цель, поэтому он читается как «сбор на старте», а не как «сюда никто не жертвует» |

Ноль в блоке цели показываем, а в hero прячем. Разница не в упрямстве: в hero цифра стоит
одна и работает как единственное социальное доказательство, в блоке цели — рядом со шкалой
и суммой цели.

Все четыре состояния собраны в [ui-kit.html](ui-kit.html#goal).

**Блокер остаётся:** цель на месяц — конкретная сумма и период — нужна от заказчика.
Состояние «месячная цель не задана» существует как честный запасной вариант, а не как
замена ответу.

## Символ ﷺ — решено

Глифа U+FDFA нет ни в Lora, ни в Golos Text; на Windows без фоллбэка он отрисуется
квадратом — в религиозном тексте недопустимо.

**Подключаем узкий `@font-face` (Amiri, OFL) с `unicode-range: U+FDFA`.** Загружается
1–2 КБ ради одного символа, зато выглядит канонично и не разрывает строку, как разорвала бы
фраза «мир ему и благословение» словами.

```css
@font-face {
  font-family: "Salawat";
  src: url("/fonts/amiri-salawat.woff2") format("woff2");
  unicode-range: U+FDFA;
  font-display: swap;
}
```
Подмешивается первым в `--font-text` и `--font-display`; остальные символы браузер берёт
из основных гарнитур.

**Вопрос к имаму остаётся:** допустимо ли сокращение в вёрстке или нужна полная формула.
Если нужна полная — меняется только текст, кит не трогаем.

## Передача на день 10

Три файла копируются в `apps/web/app/` без изменений и импортируются в `globals.css`
в порядке `tokens → kit → scene`.

Шрифты приходят из `next/font` переменными `--font-lora` и `--font-golos`; в токенах они
подставляются с фоллбэком, поэтому статические прототипы продолжают работать от CDN:

```css
--font-display: var(--font-lora, "Lora"), "PT Serif", Georgia, serif;
```

Порядок подключения важен: `tokens.css` обязан идти первым, `kit.css` переопределяет
цвет футера поверх инверсии из токенов.

## Что кит намеренно не содержит

| | Почему |
| --- | --- |
| Тёмная тема | Не в ТЗ, удваивает проверку контраста. `.on-dark` — инверсия панели, не тема |
| Вторая акцентная краска | Один акцент на весь сайт. Красный статуса ошибки — единственное исключение |
| Иконочный шрифт | Линейные иконки inline-SVG под ту же толщину штриха 2.1 |
| Тени карточек | На тёплом фоне граница работает лучше тени |
| Сетка на 12 колонок | Одностраничник: хватает `.wrap`, `.two-col`, `.three`, `.form-grid` |
| Компонент модалки | Форма открывается как bottom-sheet / `<dialog>` — верстается на дне 13 вместе с платёжным слоем |

## Что осталось на день 4

- AI-иллюстрация «цени время» — единственное изображение, которое не фото стройки.
  Обязана отличаться по стилю: псевдофото рядом с реальными снимками читается как подделка.
- Проверка на реальном телефоне, а не в браузере на десктопе.
- Показ заказчику и **заморозка дизайна**.
- Обработка фотографий стройки — не описана нигде, а на ней держится весь «дорогой» вид.
