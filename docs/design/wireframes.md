# Вайрфреймы: главная mechetshamil.ru

День 2 роудмапа · 2026-09-20 · мобайл-first

Визуальная версия: [wireframe.html](wireframe.html) — открыть в браузере, переключатель
«Мобайл / Десктоп» вверху. Здесь — спецификация: что за элемент, откуда данные, какие
состояния, что заглушка.

**Это вайрфрейм, не дизайн.** Серые прямоугольники, системный шрифт, никакой палитры.
Цвет, типографика и градиент появляются на дне 3 (UI-кит). Задача дня 2 — зафиксировать,
*что* и *в каком порядке* стоит на экране, пока это дёшево менять.

Порядок 11 блоков зафиксирован [ТЗ §5](../tz.md) и не пересматривается. Всё, что ниже
помечено **[+]**, — добавка *внутрь* существующего блока из разбора референса, не новый блок.

---

## Сквозные решения

Приняты при раскладке, влияют на несколько блоков сразу.

### 1. CTA открывает форму где угодно, а не скроллит вниз

ТЗ ставит способы оплаты последним, 11-м блоком. Это правильно по смыслу (сначала убедить,
потом просить) и плохо по конверсии: человек, готовый пожертвовать на первом экране, должен
проскроллить всю страницу.

**Решение:** любая кнопка «Пожертвовать» открывает форму как bottom-sheet (мобайл) /
модалку (десктоп). Порядок блоков не нарушен, путь до оплаты — один тап с любой высоты
скролла. В блоке 11 та же форма лежит инлайном — для тех, кто дочитал, и для SEO.

Одна форма, два места рендера. Скрытое поле `main_payment` у референса существует ровно
поэтому — у него форма тоже на странице дважды.

### 2. Sticky-шапка с кнопкой «Помочь»

56 px, логотип + название слева, primary-кнопка справа. Появляется после ухода hero
за верх экрана (на самом hero не нужна — там свой CTA крупнее). Меню нет: одностраничник,
навигация не нужна, бургер — лишний элемент.

### 3. Хадисы — заглушки с пометкой

Ни в вайрфрейме, ни в вёрстке нет текста хадиса. Вместо него — блок с видимой рамкой
«⟨ЗАГЛУШКА — ожидает выверки имамом⟩» и текст-рыба нужной длины, чтобы вёрстка знала
габариты. Смысл, пересказанный заказчиком, подписан отдельно и помечен как пересказ.
Правило из [CLAUDE.md](../../CLAUDE.md) → «Правила по контенту».

### 4. Мобайл — база, десктоп — расширение

Рисуем 390 px (iPhone 14/15 — самый частый экран у целевой аудитории). Десктоп делается
только для 4 блоков: hero, топ регионов, галерея, форма. Остальные на десктопе — та же
одна колонка, ограниченная `max-width: 720px` по центру. Это прямо экономит часы
дизайн-бюджета (риск «дизайн затягивается» из роудмапа).

### 5. Цифры — табличные

Суммы, проценты и счётчики набираются `font-variant-numeric: tabular-nums`. Без этого
счётчик собранного дёргается при каждом обновлении. Мелочь, которая видна всем.

Первый экран — **слоган и CTA, не информация**. Это прямое требование ТЗ и главное

│  [фоновый градиент + белая   │
│   линейная графика: ладони   │
│   с мечетью, статика]        │
│                              │
│  Мы поможем вам построить    │  ← H1, 32/38 моб, 56/62 деск
│  себе дом в раю за 100 ₽     │
│                              │
│  Мечеть «Шамиль» в Уфе,      │  ← подзаголовок 15/22, opacity .8
│  на 500 человек              │
│                              │
│  [ Пожертвовать от 100 ₽ ]   │  ← primary, 52 px, full-width
│  [ Поделиться сбором ]       │  ← ghost, бордер 1px белый
│                              │

│  от 1 204 человек            │
│  ▾                           │  ← скролл-аффорданс

| | |
| --- | --- |
| Высота | `88svh` — не 100: нижний край следующего блока должен выглядывать, иначе часть людей не понимает, что дальше есть страница |

## Блок 2 — Цель сбора

**[+] Двойной прогресс-бар** — главное заимствование у референса.

```
┌──────────────────────────────┐
│  Цель на сентябрь            │
│  4 300 000 из 6 000 000 ₽    │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░  72%     │  ← шкала 1, крупная, 12 px высота
│  Осталось 1 700 000 ₽        │
│                              │
│  ─────────────────────────   │
│                              │
│  Общая цель                  │
│  12 840 000 из 240 000 000 ₽ │
│  ▓░░░░░░░░░░░░░░░░░░  5,3%   │  ← шкала 2, тоньше, 6 px
│                              │
│  1 204 ·  23  ·  5 мин назад │  ← пожертвований · регионов · обновлено
│                              │
│  [ Внести свой вклад ]       │
└──────────────────────────────┘
```

Месячная шкала — **сверху и крупнее** общей. Причина в [CLAUDE.md](../../CLAUDE.md):
при цели 240 млн общая шкала на старте показывает доли процента и читается как провал.
Месячная — единственное, что спасает первый экран сбора.

| | |
| --- | --- |
| Данные | `campaign.monthly_goal`, `raised_this_period`, `goal_total`, `raised_total`, `donations_count`, `regions_count`, `updated_at` |
| Состояния | Месячная цель не задана → блок схлопывается до одной шкалы. Месячная выполнена >100% → шкала полная + «Цель месяца достигнута, собираем сверх» (не обрезать на 100%, перевыполнение — сильный сигнал) |
| Обновление | Поллинг раз в 30 с или revalidate — решается на дне 10 |

**Блокер:** цель на месяц — конкретная сумма и период. Без неё блок наполовину пустой.

## Блок 5 — Топ донатеров

Требование заказчика, у референса такого блока нет. Конфликтует с блоком 9 («садака —
скрытое поклонение») — конфликт снимается текстом прямо в блоке.

```
┌──────────────────────────────┐
│  Спасибо тем, кто разрешил   │
│  себя назвать                │  ← заголовок вместо «Топ донатеров»
│                              │
│  🥇 Наиль Х.        50 000 ₽ │
│  🥈 Аноним          32 000 ₽ │  ← аноним занимает место, но без имени
│  ...                         │
│                              │
│  Большинство жертвует        │  ← ключевая подпись, снимает конфликт
│  анонимно — и это лучшая     │
│  форма садака. В список      │
│  попадают только те, кто сам │
│  снял галочку.               │
└──────────────────────────────┘
```

| | |
| --- | --- |
| Анонимность | Чекбокс «Анонимное пожертвование» в форме **включён по умолчанию** |
| Имя | Только имя + первая буква фамилии. Полное ФИО в публичном списке — лишние ПДн |
| Состояния | Неанонимных < 3 → блок скрыт |

**Блокер:** подтвердить анонимность по умолчанию. Если заказчик хочет наполненный топ,
он скажет «выключить» — это его решение, но последствие (конфликт с блоком 9) надо озвучить.

## Блок 7 — Почему мечеть, а не больница

Снимает возражение, которое люди проговаривают вслух. Формат — вопрос крупно, ответ
разговорно, без академизма.

| | |
| --- | --- |
| Заголовок | «Почему мечеть, а не больница?» — вопросом, не утверждением |
| Аргумент | Первая постройка Пророка ﷺ после хиджры — мечеть Куба; мечеть как символ безопасности; место, которое лечит душу |
| Форма | 2–3 коротких абзаца + выделенная цитата-акцент |
| Статус текста | Исторический тезис, не хадис, но **формулировка всё равно к имаму** |

Иллюстрации нет: текстовый блок между двумя визуальными (галерея / «цени время») даёт
ритму передышку.

## Блок 10 — Финальный призыв

Тёмный градиент, крупный текст — визуально «закрывает» страницу.

Текст от заказчика почти дословно (это **его слова, не хадис** — их можно ставить сразу):

> «Мы призываем вас принять участие в благословенном деле строительства мечети.
> Помогите другим людям и своим близким тоже попасть в рай и построить себе дворцы в раю».

```
  [ Пожертвовать от 100 ₽ ]      ← primary
  Не можете сейчас? Поделитесь — ← альтернативный призыв текстом
  указавшему на благое та же
  награда                         ← ⟨заглушка⟩
  [ Поделиться ]                  ← ghost
```

Альтернативный призыв поделиться — прямое требование ТЗ §5.10. Он ловит тех, кто
дочитал, но не готов платить: это не потерянный пользователь, а бесплатный канал.

### Вкладка «По реквизитам»

Постоянный путь, не заглушка: часть жертвователей принципиально не платит картой онлайн.
Р/с, наименование, назначение платежа, QR, кнопка «Скопировать реквизиты», инструкция
«напишите нам после перевода» + контакт.

### [+] Живая лента поступлений

Под формой. Время · сумма · способ · подпись. Доказывает, что сайт живой, и
**нормализует малые суммы** — видно, что жертвуют по 10–100 ₽ и это нормально.
Прямо поддерживает слоган. Кнопка «Показать ещё», keyset-пагинация, не 2388 страниц.

**Блокеры:** платёжный агрегатор и мерчант-аккаунт; реквизиты р/с; placeholder суммы
(100 ₽ или 1 000 ₽); формулировка про комиссию.

## Служебные экраны

Не блоки главной, но без них платёж не закрывается.

### `/thanks?order_id=…` — «Спасибо»

Макет: [thanks.html](thanks.html) — все три состояния.

Опрос статуса заказа: **каждые 3 секунды, максимум 10 попыток (30 с)** — вебхук провайдера
регулярно приходит позже пользовательского редиректа. Лоадер прокручивает фразы
(«Проверяем ваш платёж…», «Убеждаемся, что ваш взнос дошёл…»), чтобы 30 секунд не читались
как зависание.

**По истечении 30 секунд донат не считается неуспешным.** Экран: «Мы ещё проверяем, деньги
не потеряны» — **не** «платёж не прошёл». У референса честной формулировки здесь нет;
это место, где мы обязаны быть лучше.

Успех → сумма, благодарность и **сразу кнопка «Поделиться»**: момент сразу после
пожертвования — пик готовности рассказать о нём.

### `/{код}/` — региональная страница

Та же главная, но: регион предвыбран в форме, его строка в рейтинге подсвечена,
**собственные OG-теги** — заголовок и картинка с суммой региона. У референса на `/2/`
теги остались общими от главной; при ставке на «поделиться» это наша бесплатная конверсия.

Макеты превью и техника генерации: [og.html](og.html).
