# Типографика

Обновлено 20.09.2026 после смены направления на podari-zhizn.ru. Предыдущее решение
(Onest + Golos Text) отменено — причина ниже.

## Решение

| Роль | Шрифт | Начертания |
| --- | --- | --- |
| Заголовки, слоган, крупные суммы | **Lora** — вариативный сериф | 500 / 600 / 700 |
| Всё остальное: текст, кнопки, поля, подписи | **Golos Text** | 400 / 500 / 600 |

Две гарнитуры, обе SIL OFL, обе вариативные, обе самохостятся через `next/font`.

## Почему сериф — и почему именно так

Разобрал CSS podari-zhizn.ru. Их визуальный язык держится на двух вещах:

| | Подари жизнь |
| --- | --- |
| Дисплейный шрифт | **SangBleu Republic** — контрастный сериф, Swiss Typefaces, коммерческий |
| Текстовый | **Styrene B** — гротеск, Commercial Type, коммерческий |
| Фон | `#faf2f0` — тёплый кремовый, не белый |
| Акцент | `#d94236`, один на весь сайт |
| Анимация | ни `@keyframes`, ни GSAP, ни Lottie во всех 463 КБ CSS |

**Сериф в заголовках — главный носитель «дорогого» ощущения.** Не палитра и не анимация:
гротеск на кремовом фоне даст обычный аккуратный лендинг, сериф даёт «фонд, которому
пятнадцать лет». Структуру повторяем: контрастный сериф + чистый гротеск. Гарнитуры берём
бесплатные — SangBleu и Styrene коммерческие, вдвоём это порядка 400 € на проект,
а бюджет на шрифты в ТЗ не обсуждался вообще.

Golos Text остаётся с прошлого дня в роли Styrene и делает ровно его работу: нейтральный
гротеск, отличная кириллица, табличные цифры.

## Отбор серифа: три кандидата отпали на проверке

Наша аудитория — Уфа, Казахстан, Кыргызстан. В рейтингах печатаются имена донатеров
и названия регионов, а все суммы — в рублях. Прогнал кандидатов по `cmap` через `fontTools`:

| Шрифт | Башкирский | Казахский | ₽ | `tnum` | Вердикт |
| --- | --- | --- | --- | --- | --- |
| **Lora** | полный | полный | есть | **есть** | **взят** |
| PT Serif | полный | полный | есть | — | годен, но статика и слабый контраст |
| Noto Serif | полный | полный | есть | — | утилитарный, без характера |
| Prata | полный | полный | есть | **нет** | **отклонён** |
| Literata | нет `Ҙ Ҡ Ҫ` | полный | есть | — | отклонён |
| Spectral | нет `Ҙ Ҡ Ҫ` | полный | есть | — | отклонён |
| Playfair Display | нет `Ҙ Ҡ Ҫ` | полный | **НЕТ** | — | **отклонён** |

Два отказа стоит объяснить отдельно.

**Playfair Display** — самый близкий по духу к SangBleu и первый кандидат: высокий контраст,
дидон, вариативный. В нём **нет знака рубля**. На сайте, который собирает рубли и печатает
`240 000 000 ₽` в самом крупном кегле на странице. Символ подставился бы из системного
фоллбэка — другой шрифт внутри главной цифры сбора.

**Prata** — визуально точнейшее попадание в SangBleu Republic. Отклонён из-за отсутствия
`tnum`: счётчик собранной суммы у нас анимируется от нуля, и без табличных цифр он будет
дёргаться по ширине на каждом кадре. Плюс единственное начертание 400.

Lora не такая драматичная, как Playfair, — контраст мягче, формы теплее. Для сбора на мечеть
это скорее плюс: дидон холодноват, а тон по ТЗ «разговорный, эмоциональный».

## Символ ﷺ — отдельная проблема

В блоке 7 текст содержит «Пророка ﷺ» (U+FDFA). **Ни в Lora, ни в Golos Text этого глифа нет.**
Без фоллбэка на Windows он отрисуется квадратом-крокозяброй — в религиозном тексте это
недопустимо.

Два пути, выбрать на дне 3:

1. Подключить узкий `@font-face` c `unicode-range: U+FDFA` (Amiri или Noto Naskh Arabic, OFL) —
   загружается 1–2 КБ ради одного символа, зато выглядит канонично.
2. Писать «мир ему и благословение» словами.

Рекомендую первый: символ привычен аудитории и короче фразы. **Вопрос к имаму заодно:**
допустимо ли сокращение в вёрстке или нужна полная формула.

## Шкала

Сериф в заголовках требует другой шкалы, чем гротеск: меньший межстрочный, отрицательный
трекинг, более крупные кегли.

| Токен | Мобайл | Десктоп | Шрифт / вес | Где |
| --- | --- | --- | --- | --- |
| `display` | 35 / 37 | 68 / 71 | Lora 600, `-0.02em` | слоган в hero |
| `h2` | 25 / 28 | 38 / 42 | Lora 600, `-0.02em` | заголовок блока |
| `h3` | 19 / 24 | 22 / 28 | Lora 600 | карточка |
| `amount-lg` | 26 / 26 | 44 / 44 | Lora 600, `tnum` | сумма в блоке цели |
| `amount-sm` | 15 / 20 | 16 / 22 | Golos Text 600, `tnum` | суммы в рейтингах и ленте |
| `body` | **17** / 27 | 17 / 27 | Golos Text 400 | абзацы |
| `lede` | 17 / 27 | 19 / 30 | Golos Text 400, `--ink-soft` | подзаголовок под слоганом |
| `small` | 14 / 21 | 14 / 21 | Golos Text 400 | подписи |
| `micro` | 12.5 / 18 | 12.5 / 18 | Golos Text 400 | комиссия, согласие на ПДн |
| `eyebrow` | 13 / 1 | 13 / 1 | Golos Text 500, `+0.06em`, caps | надзаголовок «Сбор идёт» |
| `button` | 16 / 1 | 16 / 1 | Golos Text 600 | кнопки |
| `input` | **16** / 1 | 16 / 1 | Golos Text 400 | поля формы |

Заголовки набираются через `clamp()` — промежуточные размеры не нужны, шкала непрерывна.

### Два числа, которые нельзя уменьшать

- **`body` = 17 px.** Поднял с 16: на кремовом фоне и при крупных серифных заголовках
  16 px выглядит мелко, а аудитория сбора — не только двадцатилетние.
- **`input` = 16 px.** Ниже — и Safari на iOS зумит страницу при фокусе на поле.
  Пользователь оказывается в наполовину увеличенной платёжной форме.

## Цифры

```css
font-variant-numeric: tabular-nums;
```

Есть и в Lora, и в Golos Text — проверено. Без этого анимированный счётчик собранной суммы
дёргается по ширине, а колонка сумм в рейтинге не выравнивается по разряду.

Разделитель разрядов — **узкий неразрывный пробел** `U+202F`: `12 840 000 ₽`. Форматирование
через `Intl.NumberFormat('ru-RU')` на сервере, чтобы SSR и клиент не разошлись.

Знак `₽` есть в обеих гарнитурах, `₸` — в Golos Text. Знака кыргызского сома в Unicode нет
ни у кого: пишем «сом» словом.

## Контраст: посчитано под новый фон

Фон сменился с чистого белого на тёплый кремовый `#FAF6F0`.

| Пара | Контраст | |
| --- | --- | --- |
| `#0A3367` на кремовом | 11.59 | AAA — основной текст |
| `#4A6285` на кремовом | 5.78 | AA — приглушённый текст, подписи |
| `#026AA9` на кремовом | 5.36 | AA — ссылки и акценты, **не мельче 14 px** |
| Белый на кнопке `#026AA9` | 5.77 | AA |
| Белый на `#0A3367` | 12.48 | AAA — текст на градиентной панели |

Правило с прошлого дня остаётся: **приглушённый белый (`opacity < 0.9`) допустим только
на тёмном конце градиента.** На `#026AA9` белый ниже 90% проваливает AA (4.29).

## Подключение

```ts
// app/fonts.ts
import { Lora, Golos_Text } from 'next/font/google'

export const lora = Lora({
  subsets: ['cyrillic', 'cyrillic-ext', 'latin'],
  weight: ['500', '600', '700'],
  variable: '--font-display',
  display: 'swap',
  preload: true,          // первый экран — это слоган
})

export const golos = Golos_Text({
  subsets: ['cyrillic', 'cyrillic-ext', 'latin'],
  weight: ['400', '500', '600'],
  variable: '--font-text',
  display: 'swap',
  preload: false,
})
```

- `cyrillic-ext` **обязателен** — именно он несёт `Ә Ғ Ҡ Ң Ү Һ`.
- `next/font` самохостит файлы: ни одного запроса к `fonts.googleapis.com` с боевого домена.
  На сайте, принимающем платежи, внешняя зависимость в критическом пути — лишний риск.
- В [prototype.html](prototype.html) шрифты пока подключены с CDN: это локальный
  прототип, не прод.
