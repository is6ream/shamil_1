# Отчёт фронтенда админ-панели

## Состояние на 2026-10-09

На 09.10 бэкенд закончен: B2–B9 `done`, `docs/admin/API.md` готов (`3189e6d`). Каркас ниже писался 08.10,
когда были готовы только B2 и B3, а `API.md` ещё не было. Промпт 2/2 в этом случае
велит остановиться. Первая сессия так и сделала. По решению пользователя (D-F01) фронт продолжен
**в части, не зависящей от контракта**. Всё угаданное собрано в одном файле, `apps/web/lib/admin/endpoints.ts`.

### Сделано (без API)

Коммит `feat(web-admin): каркас админки…`.

- **Сессия по D-05** — `lib/admin/api-client.ts`, `lib/admin/session.tsx`. Access-токен живёт только в замыкании
  модуля. Каждый запрос идёт с `credentials: "include"` и `Authorization: Bearer`. На 401 делается один refresh,
  общий для всех параллельных запросов, и один повтор; второй 401 выводит из админки. При загрузке вкладки
  сначала refresh, затем `/me`.
- **Роли по D-06** — `lib/admin/roles.ts`. Меню, плитки главной и доступ к разделам зависят от роли. Это только
  интерфейс: защита на API.
- **Ошибки** — `lib/admin/errors.ts`, один тип `AdminApiError` с русским текстом. Сообщения валидации сервера
  (400/409/422) показываются списком. На 403/404/413/429/5xx/сеть — свой текст, внутренности сервера наружу не идут.
- **Хуки** — `useAdminQuery` (отмена запроса, «Повторить»), `useAdminMutation` (защита от двойной отправки),
  `useUnsavedChangesWarning` (закрытие вкладки и клики по ссылкам).
- **UI-компоненты** (`components/admin/ui`) на токенах сайта: поля с label и `aria-describedby`, кнопка
  с состоянием «отправляется», модалка на `<dialog>`, подтверждение с повтором суммы, тосты (live-регион),
  загрузка/пусто/ошибка, таблица, которая на телефоне становится карточками, пагинация.
- **Страницы**: `/admin/login`, каркас с меню (на телефоне раскрывающееся, с 1024 px — колонка слева),
  главная с плитками разделов, `/admin/account` — смена пароля с проверкой до отправки, заглушки разделов,
  которые ждут API (D-F06).
- **`POST /api/revalidate`** — контракт D-F02: Bearer-секрет за постоянное время, allowlist тегов,
  `revalidateTag(tag, { expire: 0 })`. Сигнатура сверена с `next@16.3.5`.
- **`next.config.ts`**: `X-Robots-Tag: noindex` на `/admin/*` и `images.remotePatterns` из env (D-F05, D-F08).

## Env фронта

| Переменная | Где | Зачем |
| --- | --- | --- |
| `NEXT_PUBLIC_API_URL` | сборка | База API с префиксом `/api`, уже используется сайтом |
| `REVALIDATE_SECRET` | сервер Next | Тот же секрет, что у бэкенда; без него `/api/revalidate` отвечает 503 |
| `NEXT_PUBLIC_MEDIA_URL` | сборка | Публичный адрес медиа (S3 или `${API}/media`) для `next/image` |
