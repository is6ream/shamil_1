## Env фронта для Timeweb

| Переменная | Где | Зачем |
| --- | --- | --- |
| `NEXT_PUBLIC_API_URL` | сборка | База API с `/api` |
| `NEXT_PUBLIC_SITE_URL` | сборка | Адрес сайта (OG, ссылки) |
| `NEXT_PUBLIC_MEDIA_URL` | сборка | Публичный адрес бакета S3 (`S3_PUBLIC_BASE_URL` API) — без него `next/image` не покажет фото медиатеки (D-F12) |
| `REVALIDATE_SECRET` | сервер Next | Тот же, что у API; без него `/api/revalidate` отвечает 503 и правки видны только через час |
| `NODE_ENV=production` | сервер Next | Выключает `dangerouslyAllowLocalIP` (защита оптимизатора картинок) |

Сайт обязан быть на **HTTPS**: Web Locks (D-F10, две вкладки) и `crypto.randomUUID` есть только в
безопасном контексте. По `http://192.168.x.x` в локальной сети две вкладки иногда разлогинивают друг
друга — это ограничение dev, не прода.

Локально для ревалидации в `apps/web/.env.development.local` добавлен `REVALIDATE_SECRET` (файл в
`.gitignore`).

## Нужно от бэкенда

1. **ПДн в query-строке.** Поиск `GET /admin/donations?q=<телефон или имя>` и тот же `q` в CSV
   попадают в access-логи прокси/балансировщика. Нужно либо не писать query этого маршрута в логи,
   либо принимать поиск в теле `POST`. Фронт следует контракту API.md (security-review, MEDIUM).
2. **Лимит refresh 20/мин с IP.** Несколько сотрудников за одним офисным NAT, у каждого по паре вкладок,
   легко его выбирают (каждая перезагрузка страницы = refresh). Фронт теперь не выкидывает на 429, но
   показывает ошибку. Предложение: ключ лимита — семейство cookie, а не IP, или лимит выше.
3. **Короткое окно на повтор только что ротированной refresh-cookie** (было в прошлом отчёте) — для
   браузеров без Web Locks.
4. **Дописать в API.md лимиты**, которые фронт взял из DTO: галерея — подпись 300, alt 200; видео —
   ссылка 500, название 200; имя пользователя 120. Телефон в контактах: `+` только в начале
   (`^\+?[0-9 ()-]{5,30}$`), в API.md написано мягче.
5. **alt галереи 200, а alt медиатеки 300.** Если alt берётся из медиатеки по умолчанию, длинное
   описание фото может не влезть в галерею — проверить поведение сервера.
6. Пользователей нельзя удалить, только отключить: e2e-прогоны оставляют отключённых `e2e-*@test.local`.
