# Прогресс: админ-панель

Ветка `feature/admin-panel`. Сессия может прерваться — продолжать с первого шага не в статусе `done`.
Работа разделена на два агента: бэкенд (`B*`, промпт 1/2) и фронтенд (`F*`, промпт 2/2, стартует после
бэкенда и опирается на [API.md](API.md)).
