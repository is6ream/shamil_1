# План работ: админ-панель

| # | Шаг | Суть |
| --- | --- | --- |
| 0 | Анализ | ANALYSIS, PLAN, DECISIONS, PROGRESS; фикс `.gitignore` (скрытые `components/build`) |

| 5 | Контент | `content_block` (hero, about, requisites, contacts, faq), `construction_stage`, `news_post`; публичные эндпоинты; фронт с API и запасным вариантом = текущий хардкод; seed контента; ревалидация Next (`/api/revalidate`) |

| 8 | ~~Telegram~~ | **Исключён из объёма 08.10.2026.** Старт без онлайн-оплаты, пожертвования видны в дашборде. Неверная подпись колбэка — `logger.warn`; расхождение суммы — `logger.warn` + системная запись в `audit_log` (D-03) |
